# 服務建議書製作器（Electron）

依 RFP 勾選章節與區塊，產生 Markdown / Word（.docx）服務建議書；可維護範本、共用區塊庫，並以 git 保存範本版本。

## 執行
```bash
npm install
npm start          # 啟動桌面程式
npm run dist       # 打包安裝檔（electron-builder）
```

## 功能
- 製作建議書：勾選章節/區塊、RFP 關鍵字標示、匯出 .docx / .md
  - 進度列的「選擇內容」會顯示已勾選數（例如 2／23），貼上 RFP 後提示「命中 N 章、M 個區塊」；「預覽命中清單」先列出命中的章節／區塊與原因（關鍵字、章節相符），可取消不要的項目，確認後才勾選
  - 空文件沒有章節時，提供「從區塊庫選區塊」「＋新增章節」快速入口；新章節從區塊庫插入第一個區塊時，會沿用該區塊分類的章節名
  - 「範本」選單固定在製作頁最上方（手機捲動時貼在頁首下方），預設顯示「選擇範本」，選項含「空文件（不套用範本）」；與「素材與範本」分頁編輯用的範本選單各自獨立，互不影響
  - RFP 貼上區顯示參考格式（只有大項／大項＋子標題）並可「填入範例」。自動偵測大項（一、／1.／第一章）與子標題（（一）／1.1／1)）：只有大項 → 以章節為單位標示，命中的章節整章勾選；有子標題 → 以區塊為單位標示與勾選
  - 左側章節與區塊可**拖曳**（⠿）或用 ▲▼ 調整順序，區塊可跨章節移動；可隨時 ＋新增區塊（空白或從區塊庫）、✎編輯、新增章節。只影響本文件，不改動範本
  - 右側內容手動修改後會標示提醒，任何會覆蓋它的操作都會先確認
  - 「儲存到文件庫」保存整份建議書（含勾選、順序、基本資料、RFP），可再載入繼續編輯
- 文件庫：檢視（預覽）、搜尋、載入編輯、直接改文字、匯出 Word / Markdown、刪除
- 導覽：主導覽 4 群組——「製作」「文件庫」「素材與範本」（範本／區塊庫／檔案庫／Word 格式）「版本與設定」（版本歷史／設定），群組內用次導覽列切換，並記住各群組上次停留的分頁；手機／平板（≤820px）主導覽移到畫面底部。導覽列支援 ← → Home End 方向鍵。頁首「儲存變更 ●」只在有未儲存的範本／區塊庫／Word 格式變更時醒目，「素材與範本」上會出現橘點；`Ctrl/⌘+S` 在製作頁＝存入文件庫，其他頁＝儲存範本設定
- 使用流程引導：製作頁最上方的進度列（基本資料 → 選擇內容 → 檢查微調 → 儲存匯出）會依目前狀態標示完成度並提示「下一步」（按鈕直接帶你過去）；頁首「？使用流程」開啟說明（製作、初次設定、日常整理，每項都有「前往」），首次使用另有歡迎提示
- 版本歷史（需要安裝 git）：每次儲存範本、文件、檔案都會留下一個版本，並自動打上 **Tag 編號**（`v0001`、`v0002`…，git 附註標籤）。可替任一版本取**版本名稱**（例如「投標版定稿」，存在 Tag 的說明文字），列表會顯示 Tag 與名稱，搜尋框可依說明、Tag 編號、版本名稱搜尋；升級前的舊版本會在第一次啟動時依時間補上編號。「版本歷史」分頁可依範圍（全部／文件／範本／檔案）與關鍵字瀏覽紀錄；點選紀錄可看變更了哪些檔案、預覽文件、對照差異（文件為逐行差異，範本為章節／區塊／區塊庫／Word 格式的增刪修摘要）；可把單一文件或整份範本還原到「此版本」或「變更前」；「已刪除的文件」可預覽並找回。文件庫中每份文件也有「版本歷史」按鈕，可預覽、對照上一版／目前、還原。還原一律建立新版本，不會刪除任何紀錄
- 文件庫進階：排序（更新／建立時間、標題）、依範本／標籤／日期篩選、含內文的全文搜尋；標籤與星號釘選（釘選者固定排最上面）；複製、重新命名；多選後批次加／移除標籤、釘選、匯出 Word／Markdown 到資料夾（頁首頁尾變數取各文件自己的基本資料）、刪除；「備份文件庫」匯出成單一 JSON（含文件用到的圖片），「匯入備份」時相同內容自動略過、同編號但內容不同者另存為「（匯入）」副本，不會覆蓋
- 檔案庫進階：排序（時間／名稱／大小／類型）、標籤與依標籤篩選；圖片顯示被幾份文件使用，可篩出「未使用的圖片」清理；多選後批次加／移除標籤、匯出到資料夾、刪除（會列出使用中的文件）；「從資料夾匯入」一次加入整個資料夾（不含子資料夾，最多 500 個）
- 檔案庫：集中管理上傳的圖片與附件（PDF、Office 檔等任何類型，單檔上限 100 MB）。可搜尋、依類型篩選、預覽圖片、圖片一鍵插入目前建議書、附件開啟／另存副本／在資料夾顯示、重新命名、刪除（刪除圖片前會列出引用它的文件）。程式／腳本類附件（.exe、.bat、.sh…）不會直接開啟
- 設定：可分別指定「圖片」與「附件」的儲存路徑（可指到公司共用資料夾），變更時可選擇同時搬移現有檔案（先複製驗證、全部成功才刪原檔，只搬本程式上傳的檔案）；路徑不可用時自動退回預設並提示。設定存於 `userData/settings.json`，屬於這台電腦，不進範本版本紀錄
- Word 格式：可建立多組格式範本（字型、字級、顏色、行距、紙張/方向/邊界、頁首頁尾、頁碼、每章換頁），匯出 Word 時套用；可複製、匯入、匯出，含即時預覽
- RWD：桌面雙欄、平板縮欄、手機單欄堆疊；觸控裝置以 ▲▼ 取代拖曳
- 維護範本：章節與區塊的新增、排序、刪除、編輯；範本複製、匯入、匯出
- 區塊庫：內建範本（軟體開發案、維護案）的所有區塊 + 共用聲明，依「範本｜章節」分類，可依分類篩選、搜尋、編輯、插入任一章節；兩範本內容相同的區塊歸「共用｜…」只留一份
- 版本紀錄：每次「儲存」自動 git commit 並打上 Tag，可還原（需安裝 git）；儲存範本／區塊庫／Word 格式時可順便填「版本名稱」（選填），直接寫入該版本的 Tag

### 範本資料的存放方式（JSON 索引 + Markdown 區塊檔）
範本資料存放於使用者資料夾的 `data/`（Windows：`%APPDATA%/proposal-builder/data`），區塊內文拆成 Markdown 檔並用資料夾管理，`templates.json` 只是 **UTF-8 索引檔**：

```
data/
├─ templates.json            ← 索引檔：範本／章節／區塊的名稱、順序、關鍵字、Word 格式（不含內文）
├─ templates/
│  ├─ T001/                  ← 範本 001
│  │  ├─ C01/                ← 章節 01
│  │  │  ├─ B0001.md         ← 區塊 0001 的內文
│  │  │  └─ B0002.md
│  │  └─ C02/ …
│  └─ T002/ …
└─ library/
   └─ L0001.md               ← 區塊庫的區塊內文
```

- 檔名一律使用**編號**（`T001`、`C01`、`B0001`、`L0001`），不含中文或特殊字元，避免不同系統／壓縮工具造成檔名亂碼；標題只存在索引檔裡。
- 編號建立後固定不變：區塊移到別的章節只會換資料夾、重新排序只改索引檔；複製範本會重新編號，不與原範本共用檔案。
- 索引檔內每個區塊有 `file` 欄位指向其 md 檔；md 檔內容就是區塊的 Markdown 內文（可用任何文字編輯器修改，重新載入即生效）。
- 舊版（內文內嵌在 `templates.json`）的資料，第一次啟動時會自動轉換並留下一個版本。
- 每次「儲存」會一起提交索引檔與 md 檔；版本歷史的差異摘要、還原都會把索引與 md 組回完整範本。

Word 格式範本存於同一個 `templates.json`（`wordStyles`），會一併納入 git 版本紀錄。頁首/頁尾文字可使用 {{案名}} {{機關}} {{公司}} {{日期}}。

附件預設存於 `data/attachments`（已加入該資料夾的 .gitignore，不進版本控管）；圖片預設存於 `data/images`。附件不會嵌入 Word 匯出檔。

標籤與檔案名稱索引存於 `data/files-index.json`（納入 git）。git 提交已序列化，批次操作不會因同時提交而衝突。
